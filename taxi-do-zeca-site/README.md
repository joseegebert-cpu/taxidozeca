# Landing page — Táxi do Zeca

Site estático pronto para subir no GitHub, Vercel, Netlify ou qualquer hospedagem.

## Como usar

1. Descompacte o arquivo ZIP.
2. Suba a pasta inteira para um repositório no GitHub.
3. Na Vercel, importe o repositório.
4. Framework preset: **Other**.
5. Build command: deixe vazio.
6. Output directory: deixe vazio ou use `/`.
7. Deploy.

## Arquivos principais

- `index.html` — página principal.
- `style.css` — estilos da landing page.
- `assets/logo-negativa.svg` — logo para fundo preto.
- `assets/logo-principal.svg` — logo para fundo claro.
- `assets/logo-circular.svg` — versão circular para perfil.
- `assets/carro-taxi.svg` — ilustração vetorial do carro.
- `assets/favicon.svg` — ícone do site.

## Personalização

Para usar a logo/carro oficial em PNG, substitua os arquivos dentro de `assets/` mantendo o mesmo nome ou atualize os caminhos no `index.html`.
